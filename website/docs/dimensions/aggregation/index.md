# Aggregation and federated optimization

Start with [FedSGD](fedsgd.md) to see gradients averaged at a common model, then study [FedAvg](fedavg.md) and its complete worked round. Continue through server momentum, proximal local training, control variates, and adaptive server optimization.

The robust-aggregation notes introduce a separate question: what if some submitted contributions are corrupted? They explain the rules and their assumptions without treating optimization methods as security guarantees.

Every note below has equations, an original worked example, limitations, self-checks, and primary sources. These are sourced learning notes, not reproduced experiments or a completed critical literature review. A structured comparison module remains pending.
